📲 Background timer notifications
This connects the GitHub Pages planner to a free Cloudflare Worker. When a timer finishes, the notification can appear even if you switch apps, lock the iPad, or close the planner.
Paste your Cloudflare Worker URL above, save it, then enable notifications.
iPhone/iPad: first open this GitHub Pages site in Safari → Share → Add to Home Screen. Then open the Home Screen app and enable notifications from there.
🔊 Alarm sound
Phone browsers may limit maximum loudness. The urgent alarm uses a repeated pattern so it is easier to notice even if the absolute volume is capped.
